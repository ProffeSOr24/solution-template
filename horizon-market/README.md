# HORIZON — маркетплейс видеоигр

Минималистичный сайт-магазин игр в космической эстетике: чёрная дыра, звёзды, замедление времени.

Запуск: просто откройте `index.html` в браузере (сборка и зависимости не нужны).

## Что внутри
- **Чёрная дыра на canvas**: аккреционный диск, гравитационное линзирование, доплеровская яркость.
- **Падение за горизонт**: при прокрутке дыра растёт, звёзды вытягиваются к центру.
- **Гравитация курсора**: звёзды притягиваются к указателю мыши.
- **Замедление времени**: «1 час здесь = 7 лет на Земле», счётчик сохраняется между визитами.
- **Каталог**: поиск, фильтр по жанрам, сортировка, 3D-наклон карточек, процедурные обложки.
- **Карточка игры** в модальном окне, **корзина** («Грузовой отсек»), которая хранится в localStorage.
- **Эмбиент-звук** на Web Audio (органный дрон, включается кнопкой).
- Если уйти на другую вкладку, заголовок станет «Вернитесь… на Земле проходят годы».
- Адаптивная вёрстка, поддержка `prefers-reduced-motion`.

Файлы: `index.html`, `styles.css`, `app.js`.
